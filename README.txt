CLAY SHOOTING GAME — v27 (PC recommended)
========================================

Current playable game:
https://yossanjp.github.io/clay-shooting-game/

Source repository (main branch):
https://github.com/yossanJP/clay-shooting-game

Desktop: mouse to aim, left-click to shoot, R / right-click to reload.
Mobile: left thumb trackpad to aim (LOW / MID / HIGH), right-side SHOOT / RELOAD.
60-second fixed-pattern challenge, 2 shells, gold clays at 15/30/45s,
combo and speed bonuses, premium results screen, offline shooting coach.
